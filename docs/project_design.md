## Testing and Performance Analysis

### Testing Environment
- Programming Language: C
- Compiler: GCC
- IDE: Visual Studio Code
- Operating System: Windows
- Data Structure: Weighted Undirected Graph
- Graph Representation: Adjacency List

### Testing Methods
1. Product search testing
2. Graph construction testing
3. BFS traversal testing
4. DFS traversal testing
5. Recommendation accuracy testing
6. Invalid input testing

### Performance Analysis
- Linear Search: O(n)
- BFS: O(V + E)
- DFS: O(V + E)
- Merge Sort: O(n log n)
- Recommendation Scoring: O(V + E)

### Dataset
The system uses five sample purchase transactions
and seven sample products.
The dataset is synthetic.
